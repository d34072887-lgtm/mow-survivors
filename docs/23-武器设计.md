# 23 — 武器设计 Weapon

> **定稿 v1.1** — 6 格全武器；合成同 ID；成长以附魔为主；**白值只改 18 条主属性**。

---

## 1. 定位

| 项 | 规则 |
|----|------|
| 栏位 | **6 格全部为武器** |
| 输出 | 6 把 **各自独立自动攻击**，伤害系数 **100%** |
| 合成 | **同 ID + 同品质** → 升一档品质 |
| 生存 | **不在武器** → [24-道具](./24-道具设计.md) |
| 成长 | **附魔(主) > 合成开槽 > 强化(辅) > 局内升级** |

武器管 **攻击模式 + 白值**；不替英雄给回血、不填 `captureRate` / `digRare` 等废弃 StatId。

## 3. 品质与合成

| 品质 | 攻击系数 | 附魔槽 | 强化上限 |
|------|----------|--------|----------|
| 白 | 1.0× | 1 | +7 |
| 绿 | 1.2× | 2 | +9 |
| 蓝 | 1.4× | 3 | +11 |
| 紫 | 1.7× | 4 | +12 |
| 橙 | 2.0× | 5 | +15 |

```typescript
mergeWeapon(a, b) {
  assert(a.id === b.id && a.quality === b.quality)
  return { id: a.id, quality: nextQuality(a.quality), enhanceLevel: 0 }
}
```

## 4. 武器白值（StatId）

只使用 [25 §2.2](./25-属性系统设计.md) **18 条主属性** + ③ Build 附魔词条：

| 常见白值 | 说明 |
|----------|------|
| `attack` | 主输出 |
| `attackSpeed` | 射速 / 挥砍频率 |
| `critRate` | 基础暴击 |
| `range` | 模式射程缩放 |
| `pierce` | 穿透类武器 |

**禁止** 武器 base：`captureRate`、`digRare`、`captureBonus` 字段。

赌狗向用 `gambleSideEffect`（③ 风险 stat，如 `auctionSnatchRate`），tooltip 红字。

## 5. Tag 与道具联动

```typescript
WeaponConfig {
  tags: string[]   // 与道具 build tag 对齐
}
```

| tag | 含义 | 联动道具示例 |
|-----|------|--------------|
| `burst` | 连射 | 过浓咖啡、胡椒弹壳 |
| `pierce` | 穿透 | 穿甲钉 |
| `melee` | 近战 | 胶带、重靴 |
| `orbit` | 环绕 | 陀螺芯 |
| `aoe` | 范围 | 地脉石 |

道具 `perStack` **线性**加成；同 tag 武器吃满层（无 3/6/9 里程碑）。

---

## 6. 局内升级

同 ID 武器花金币升 `weaponUpgradeLevel` 0~5，每级 **+8%** 该武器白值 attack；局结束清零。  
折扣读 **wealth / ③ weaponUpgradeDiscount**。

| `wpn_heavy_maul` | 重锤 | melee_arc | melee, tank | attack +12, range -5% | 高白值低攻速 |

### 8.1 数值锚点（白装、1 把）

- 入门总 attack 白值（6 格全短刀）：约 48 raw → 配合英雄底子与道具叠层  
- 单把 `wpn_glass_blade` 攻高但 **不自带 luck** — 赌狗靠道具/属性选 luck  
- 6 格可重复同 ID（合成升品质）或混搭 tag

### 8.2 合成 / 附魔示例路线

```
回合 3：2×白胡椒冲锋枪 → 绿胡椒（2 附魔槽）
回合 8：打书「攻击 +8%」「暴击 +5%」
回合 12：2×绿 → 蓝（3 槽）；可选强化 +3（辅）
```

## 9. 与道具 / 英雄

```
秒伤 ≈ Σ(6 武器模式输出 × 最终 attack × 攻速)
     × 道具 perStack
     × 英雄 base + 4选1
     + 宠物 / 技能
```

- 英雄只给 **方向**；武器给 **模式**；道具给 **18 属性叠层与条件**  
- 抓宠 / 挖宝 / 强化成功率 → **读 25 多通道联动**，不在武器上挂专用 stat
