# 22 — 英雄创意库

[← 返回索引](./README.md) | 平衡总则：[03-英雄模块](./03-英雄模块.md)

> 扩展用英雄点子。每位英雄 **必须同时有主动 + 被动**（各 1 个，技能独立配置文件）。

---

## 英雄条目模板（开发 / 策划必填）

```markdown
### 「名字」称号

- **流派**：tank / dps / treasure / capture / gambler …
- **长板**：…
- **短板**：…
- **主动「技能名」**：CD / 消耗 / 效果（战斗或非战斗）
- **被动「技能名」**：常驻或触发效果
- **好玩点**：…
```

配置路径：

```
data/configs/heroes/{id}.json          → activeSkillId + passiveSkillId
data/configs/skills/active/{id}.json
data/configs/skills/passive/{id}.json
```

---

## 设计筛选标准

1. **一条长板明显**，战斗或生存至少一块明显瘸
2. 能跟 **强化 / 附魔 / 赌场 / 拍卖 / 抓宠 / 挖宝** 至少一条线互动
3. 有 **赌** 或 **养成堆叠** 的决策
4. **主动 + 被动缺一不可** — 主动负责「按键/时机」，被动负责「流派底色」

## 创意：坦克线

### 「铁幕」瓦勒里

- **流派**：`tank`
- **长板**：护盾、减伤、嘲讽范围
- **短板**：攻击极低，无回血
- **主动「铁幕展开」**（CD 14s）：展开护盾吸收 **英雄最大生命 25%** 的伤害，持续 4s；破盾后 **3s 内无法再次开盾**
- **被动「荆棘铁壁」**：护盾存在时，受到的伤害 **5%** 反弹给攻击者（反伤装可叠）
- **好玩点**：破盾后的空窗赌走位；回血全靠装备

### 「秤砣」老沉

- **流派**：`tank`
- **长板**：最大生命全英雄最高
- **短板**：移速 -25%，攻速慢
- **主动「沉锚站桩」**（CD 16s）：**3s 内无法移动**，减伤 **40%**；结束后下一击伤害 **+30%**（鼓励站桩挨打后摸一下）
- **被动「越沉越肉」**：当前生命百分比越高，商店属性刷新里 **生命词条权重 +X%**（生命越高越难割草，但血牛）
- **好玩点**：纯叠血 build，靠走位磨回合

## 创意：输出线

### 「连珠」菲恩

- **流派**：`dps`
- **长板**：暴击、攻速
- **短板**：生命 70%，无捕获/挖宝
- **主动「血线连珠」**（CD 8s）：下一击 **必暴击**；消耗 **当前生命 5%**（可致死）
- **被动「快指」**：攻速 +12%，暴击伤害 +8%
- **好玩点**：血换爆发，吸血装续航

### 「过热」焰心

- **流派**：`dps`
- **长板**：技能伤害随战斗时间上升
- **短板**：前 10 秒面板极弱（攻击 -30%，每秒恢复 +5% 直到正常）
- **主动「过载点燃」**（CD 20s）：**5s 内**技能伤害 +50%，结束后 **2s 眩晕自己**（无法移动攻击）
- **被动「炉心」**：每 **15s** 全屏灼烧一次，伤害 = **已强化装备件数 × 固定值**
- **好玩点**：鼓励强化装备；开局弱、中后期烫

## 创意：赌狗 / 场所联动

### 「千面」赌圣

- **流派**：`gambler`
- **长板**：赌场胜率 +5%，打手触发净赢阈值 **+20%**
- **短板**：拍卖 `instant_snatch` 概率 **+50%**
- **主动「双面下注」**（赌场内 CD 0，每 visit 限 3 次）：本次赌局 **下注额 ×2**，赢则奖励 ×2，输则扣除 ×2
- **被动「千面运气」**：进赌场时可预览 **下一局** 胜率（高/低），不影响结果只给信息
- **好玩点**：专业赌场；拍卖行地狱

### 「砍价」商姑

- **流派**：`economy`
- **长板**：商店刷新便宜、拍卖可见 NPC 心理价
- **短板**：战斗属性平庸（攻击 72%，生命 75%）
- **主动「清仓吆喝」**（每回合 1 次，商店阶段）：本回合商店 **免费刷新 1 次**
- **被动「砍价眼」**：商店刷新费用 -20%；拍卖行显示 NPC **最高出价上限**（模糊区间）
- **好玩点**：经济流捡漏

### 「碎匠」回收者

- **流派**：`enhance`
- **长板**：碎装返还材料；附魔覆盖有概率保留
- **短板**：攻击 -20%
- **主动「故意手滑」**（强化室内，CD 无）：下一次强化 **成功率 +15%**，若仍失败则 **碎装返还强化石 +1**（仅限本次）
- **被动「碎中有宝」**：装备 **碎装** 时返还 **50%** 强化石；附魔 **覆盖** 时 **30%** 保留被盖掉的那条旧词条
- **好玩点**：跟强化室碎装机制绑定

## 创意：附魔 / 强化特化

### 「书呆子」墨符

- **流派**：`enchant`
- **长板**：附魔新增稀有权重；保护符空槽追加
- **短板**：生命 60%，不能抓宠
- **主动「条文预览」**（附魔台内）：预览本次附魔石可能出的 **3 个词条**（仍随机覆盖，只增信息）
- **被动「符文亲和」**：附魔 **新增** 时稀有词条权重 +25%；使用保护符时 **多保护 1 个空槽逻辑**（强制只新增）
- **好玩点**：打书党；战斗靠词条堆

### 「锻魂」铁手

- **流派**：`enhance`
- **长板**：强化成功率 +8%
- **短板**：附魔时 UI 显示「覆盖风险 +1 档」压迫感（实际概率不变，心理 debuff）
- **主动「趁热打铁」**（强化室内，CD 30s）：连续 **3 次** 强化尝试，期间成功率 **+10%**；若中途碎装仍按正常规则
- **被动「锻魂回响」**：单次强化到 **+10 以上** 成功时，全队（含宠物）获得 **3s 攻击 +5%** 可叠 3 层
- **好玩点**：强化室常客；跟保护石经济绑定

## 创意：抓宠变体

### 「共生体」孢母

- **流派**：`capture`
- **长板**：单宠出战，合并 stack **双倍计战力**
- **短板**：出战上限锁 **1**，攻击 55%
- **主动「孢子同化」**（CD 15s）：**6s 内**击杀的怪若捕获成功，`stackCount` **额外 +1**（与合并叠加）
- **被动「单体共生」**：仅 **1 只** 宠物可出战；该宠战力按 `stackCount` 算时 **×2**
- **好玩点**：一只满 stack Boss 当半个队

### 「放牧人」老马

- **流派**：`capture`
- **长板**：出战 +2；海量弱宠
- **短板**：宠物 **不能合并精英以上** 种类（只能堆普通种）
- **主动「牧群驱赶」**（CD 12s）：所有出战宠物 **3s 内移速 +50%**，集火最近精英/Boss
- **被动「人马合一」**：每多 **1 只** 出战宠物，英雄移速 **+3%**（最多 +18%）
- **好玩点**：与皮囊「6 Boss」相反，弱宠海 + 跑位

## 创意：奇怪但好玩

### 「祭品」血契

- **流派**：`risk`
- **长板**：用命换成长
- **短板**：常态极脆（生命 65%）
- **主动「血之献祭」**（每 2 回合 1 次）：立刻损失 **30% 当前生命**；下一次属性 4 选 1 **必出 1 条传说级**
- **被动「契约代价」**：生命低于 50% 时，捕获率 / 挖宝稀有权重 **+10%**（残血赌狗）
- **好玩点**：用命换属性，再靠装备回血

### 「镜像」二重

- **流派**：`utility`
- **长板**：装备效果临时翻倍
- **短板**：CD 极长，攻击 65%
- **主动「镜影复制」**（CD 90s，战斗内）：复制装备栏 **1 件** 装备的 **白值效果**，持续 **本回合剩余时间**（不复制强化/附魔）
- **被动「虚像」**：受到致命伤时 **1 次/局** 免死并清空该装备复制冷却（若本回合已用过复制）
- **好玩点**：橙装白值爆发一分钟

### 「迟到」慢郎

- **流派**：`dps`
- **长板**：回合后半段爆发
- **短板**：回合开局极弱
- **主动「赶时间」**（CD 25s）：立刻 **跳过** 剩余「迟到无敌期」，并获得 **5s 攻击 +40%**（结束无敌不能攻击的状态）
- **被动「迟到免战」**：每战斗回合 **前 5s** 无敌但 **无法攻击**；5s 后攻击 **+50%** 至回合结束
- **好玩点**：开局纯走位，后半割草

## 配置约定

每个英雄 **3 个文件**，`HeroConfig` 必须填 `activeSkillId` + `passiveSkillId`：

```
data/configs/heroes/{id}.json
data/configs/skills/active/{skillId}.json
data/configs/skills/passive/{skillId}.json
```

入库前跑 [03-英雄模块](./03-英雄模块.md) 平衡校验；缺主动或被动 **拒绝入库**。
