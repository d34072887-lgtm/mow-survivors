# 26 — 手机版美术与界面约定

[← 返回索引](./README.md)

> 版本：v1.0 | 状态：**已定稿（产品/美术约束）** | 最后更新：2026-06-26  
> 适用：**竖屏手机 Web 版**（本项目 **不做 PC 横屏主版本**）

本文档锁定 **用户气质、画面尺度、界面形态** 与 **禁止事项**。玩法数值仍以各模块 doc 为准；与本文冲突时，**美术与界面以本文为准**，玩法以模块 doc 为准。

---

## 1. 产品定位（用户画像）

| 项 | 约定 |
|----|------|
| **核心用户** | **女生偏多** 的休闲玩家（非硬核动作党） |
| **诉求** | 好看、好懂、能收集/养成、单局不太长、单手能玩 |
| **气质** | 软、可爱、有赌狗刺激但 **不压迫**（「试试手气」而非「梭哈」） |
| **招牌体验** | 抓宠合并、回合商店、暖色特殊场所（赌场/附魔等） |
| **对标气质** | **不是**复刻星露谷物语；吸收其 **「人小、地图大、看着舒服」**，结合幸存者割草 + 赌狗养成 |

---

## 2. 平台与屏幕（竖屏唯一）

| 项 | 约定 |
|----|------|
| **发布形态** | **手机浏览器竖屏 Web 游戏**（PWA 可后续做，非首期必须） |
| **屏幕方向** | **仅竖屏 9:16**；逻辑设计宽 **390px**（随 `devicePixelRatio` 高清渲染） |
| ** playable 区域** | 约占屏高 **75%～85%**（上方战场，下方留给操作与拇指） |
| **操作** | **单手**；虚拟摇杆 **或** 跟指移动（**二选一**，全项目统一，不得两套并存） |
| **局内移速** | 参考 [canvas-vampire-survivors](https://github.com/ricardo-foundry/canvas-vampire-survivors) `PLAYER_SPEED=240px/s@1200宽`，缩放到 390 宽后 **×0.3～0.35**（大地图小人偏慢）；摇杆 **15% 死区 + 推力曲线** |
| **触控目标** | 可点控件最小 **44×44 CSS px** |

### 禁止（平台）

- ❌ **禁止**以 PC 横屏、1920 宽布局作为默认或主入口  
- ❌ **禁止**要求键盘为主要操作（方向键仅可用于开发预览）  
- ❌ **禁止**在未声明支持的情况下做桌面端专属 UI 分支

## 3. 美术分层（局内 / 局外）

```
┌─────────────────────────────────────┐
│  UI / 弹窗层：暖色手绘水彩 + 手帐圆角   │  主界面、选英雄、商店、四选一、赌场
├─────────────────────────────────────┤
│  HUD 层：扁平图标、细条、大触控区       │  血条、金币、回合计时（不抢画面）
├─────────────────────────────────────┤
│  世界层：tile 地图 + 小 chibi 像素      │  局内割草战场（地图大、人物小）
└─────────────────────────────────────┘
```

| 层级 | 风格 | 参考目录 |
|------|------|----------|
| **局内角色 / 怪物 / 子弹** | 可爱 **小号 chibi 像素**（`pixel_inspired`，非 HD 插画像素） | `assets/characters/`、`assets/monsters/` |
| **局内地图** | **16×16 或 32×32** 草地/路 **tile** 拼接，镜头跟随 | 待建 `assets/tiles/` |
| **局外 / 全屏弹窗** | **暖色手绘水彩**（已定调） | `docs/preview/art-*-warm-watercolor.png` |
| **图标 / 按钮** | 柔粉、奶油白、鼠尾草绿、蜜金点缀；圆角 | 待建 `assets/ui/` |

### 局内尺寸（屏上目标，验收用）

| 对象 | 竖屏上视觉高度（约） |
|------|----------------------|
| 玩家角色 | **24～40 px** |
| 普通小怪（如史莱姆） | **16～24 px** |
| 精英 | 约为小怪的 **1.5～2 倍** |
| Boss | 约为玩家的 **2～3 倍**（仍不可占满半屏） |

> 当前 `assets/` 内 AI 预览用 sheet **偏大**，仅作占位；正式素材须按上表重出或缩放验收。

## 4. 地图与镜头（大地图 + 小人）

| 项 | 约定 |
|----|------|
| **地图语义** | 「大」= **世界逻辑坐标大** + **相机跟随玩家**，非单张巨图铺满屏 |
| **实现** | `tilemap` 分块；单局可先 **2000×2000** 逻辑像素量级试玩 |
| **相机** | 玩家锚点在屏幕 **偏下 1/3**（拇指不挡怪、上方留战场） |
| **同屏** | 怪 **多而小**、可读；特效 **轻量**，避免满屏闪光 |
| **技术** | HTML + Canvas 即可；怪物 **对象池**；tile 复用 |

### 禁止（地图 / 镜头）

- ❌ **禁止**局内用整张水彩插画当地面（水彩 **仅** 场外/UI 背景）  
- ❌ **禁止**玩家角色屏上过大（超过 **48px 高** 须重做素材或缩放到规范内并记录）  
- ❌ **禁止**固定镜头不跟随导致「小人贴边看不见周围怪」

## 5. 界面结构（竖屏信息架构）

仅维护 **手机竖屏一条线**：

```text
[启动] 水彩标题
   ↓
[主界面] 看板英雄 + 陪伴文案 + 今日试手气 + 宠物羁绊  →  preview/main-screen.html
   ↓
[局内] 上：战场 / 下：摇杆区 + 技能大按钮
   ↓
[回合间] 底部抽屉 或 全屏卡片 — 商店 / 四选一 / 特殊场所
```

### 5.1 主界面（女生向 · 参考乙女/恋与类结构）

> **预览**：[`docs/preview/main-screen.html`](./preview/main-screen.html)（竖屏 390 逻辑宽）  
> **借鉴气质**：《恋与深空》等热门女性向产品的 **界面节奏**，**不是**恋爱剧情、不复刻其科幻冷色视觉。

| 乙女/恋与类抓点 | 本项目转化 | 禁止误用 |
|----------------|------------|----------|
| **看板大立绘** — 角色占屏、有存在感 | 主推 **小葵** 水彩半身（占位可先用像素帧） | ❌ 抄角色/Logo/配音式恋爱台词 |
| **陪伴感文案** — 角色主动说话 | 抓宠/冒险语气轮播（「今天幸运值不错…」） | ❌ 暧昧约会、独占式恋爱叙事 |
| **资源条清晰** — 金币/钻一眼可见 | 🪙 金币 + 🍀 幸运值（对齐 StatId） | ❌ 逼氪式红字倒计时 |
| **今日运势/签到** | **今日试手气**（商店刷新优惠等） | ❌ 「梭哈」「 all in 」 |
| **羁绊/好感可视化** | **宠物羁绊条 + 6 格宠物栏** | ❌ 好感度送花约会 |
| **邮件/任务侧入口** | 右上角 ✉️ 📋（44px 触控） | ❌ 弹窗堆叠 >2 层 |
| **大 CTA「出发」** | 进入局内（链到 battle demo） | ❌ 小按钮藏在二级菜单 |
| **底栏 5 Tab** | 首页 / 英雄 / 战斗 / 收藏 / 更多 | ❌ PC 多级菜单 |
| **Premium 玻璃 UI** | 暖色磨砂 + 蜜金点缀 | ❌ 紫白渐变主视觉、霓虹赛博 |
| **脸部安全区** | 脸居中偏上；台词在顶栏下，卡片在底部渐变带 | ❌ 对话框/卡片盖住半张脸 |

**布局铁律**：立绘脸与胸上区（约屏高 **0～58%**）**不得**被 UI 遮挡。

**极简原则（主界面 v2）**：一屏只回答三件事——**看谁、听一句、点出发**；羁绊/试手气/任务/商店收进 **底部 sheet**，不在看板上堆卡片。

**主界面禁止项（追加）**：

- ❌ 把主界面做成 **硬核数值面板** 或 **满屏列表**（女生向需「先看人、再点出发」）  
- ❌ 主界面 **横屏** 或 **无看板立绘** 的纯工具入口  
- ❌ 使用 **恋与深空/其他 IP** 素材、角色名、界面截图拼贴  
- ❌ 主视觉 **冷色科幻深空**（与本项目暖色水彩冲突）  
- ❌ 对话框/卡片遮挡看板 **脸部区域**
- ❌ 主界面 **同时展示 2 张以上功能卡片**（应合并为一条状态或 sheet）

**待补资产**：更多英雄水彩半身 → `docs/preview/hero-{id}-portrait-warm-watercolor.png`（prompt 见技能库 `mobile-casual-game-ui/references/portrait-home-screen.md`）。

**技能库**：竖屏 UI / 立绘 / sprite 分工 → `D:\桌面\开发中控台\技能\游戏\mobile-casual-game-ui\SKILL.md`

| 场景 | 要点 |
|------|------|
| **局内 HUD** | 血条、金币、回合倒计时 — **贴边细条**；中间留给走位 |
| **局内协调感** | 尺度/移速/镜头/刷怪/特效从同一 `TUNING` 推导；走步动画随实际移速；Y 轴排序；暖色草地与主界面同 palette |
| **商店 / 赌局** | **大按钮、少字**；文案偏轻松，避免硬核金融腔 |
| **抓宠 / 图鉴** | 合并进度、宠物格子 **可视化**（女生向收集感） |
| **字体** | 圆润无衬线（如思源圆体、HarmonyOS Sans）；**禁止** Inter/Roboto 作为品牌默认 |

### 禁止（界面）

- ❌ **禁止** PC 式多级菜单、悬停 tooltip 作为主要交互  
- ❌ **禁止**局内弹窗堆叠超过 **2 层**（防小屏失控）  
- ❌ **禁止**紫白渐变、霓虹赛博、硬核暗黑作为主视觉（与已定水彩 + 软像素冲突）  
- ❌ **禁止**满屏红字警告、血腥 gore 向表现

## 6. 用户向内容倾向

| 推荐 | 慎用 / 禁止 |
|------|-------------|
| 蠢萌史莱姆、宠物蛋、合并光效 | 写实血腥、恐怖压迫 |
| 「试试手气」「刷新看看」 | 「梭哈」「 all in 」主文案 |
| 小葵等 **抓宠线** 作首发英雄候选 | 纯硬核数值墙无反馈 |
| 单局 **3～8 分钟** 节奏感 | 强制长时间连续局 |

## 8. 开发任务禁止事项（美术 / 界面专项）

以下在 **未改本文档前** 一律禁止：

1. ❌ 做 **横屏** 为主的游戏界面或默认 `viewport` 横屏布局  
2. ❌ 做 **PC 专属** 操作说明、宽屏 HUD、键鼠依赖玩法  
3. ❌ 局内采用 **暖色水彩全幅背景** 或 **HD 大立绘像素人** 作为正式角色规格  
4. ❌ 复刻 **星露谷 16px 农场风** 作为唯一标准（本项目是 **稍大的可爱 chibi**，见 §3 尺寸表）  
5. ❌ 赛博朋克 / 霓虹赌场 / 黑客风 UI  
6. ❌ 未更新 `manifest` 与 trim 流程，直接把 AI 概念图当局内 sprite 用  
7. ❌ 缩小女生向收集反馈（图鉴、合并、宠物栏）以「省 UI」  
8. ❌ 在业务代码仓新增 `.cursor/rules`、`AGENTS.md` 等工具规则覆盖本文（除非用户明确要求）
