# 11 — 抓宠模块 Capture

[← 返回索引](./README.md) | 英雄范例：[20-抓宠英雄设计](./20-抓宠英雄设计.md)

> **定稿 v0.7** — 宠物 **无等级**；同种 **数量合并变强**；后期可带多只 Boss 宠出战。

---

## 1. 定位

仅 **抓宠职业** 击杀后 **自动概率捕获**。宠物没有传统「等级 LV」，战力完全来自 **抓到多少同类、合并多少次**。

---

## 2. 核心机制：数量合并，不是升级

### 2.1 宠物没有等级

```typescript
// ❌ 没有 petLevel: 12 这种字段
CapturedPet {
  speciesId: string           // 种类，如 pet_slime / pet_boss_dragon
  speciesTier: 'normal' | 'elite' | 'boss'  // 种类档位（怪本身档次）
  stackCount: number          // 已合并的同类数量
  powerIndex: number          // 由 stackCount 查表得出的战力档，非玩家升的「级」
}
```

### 2.2 捕获 → 自动合并

```
击杀可捕获怪 → 自动消耗精灵球 → roll 概率
  成功：
    若栏内已有同 speciesId → stackCount +1 → 按表刷新 powerIndex / 属性
    若没有 → 新占 1 格，stackCount = 1
  失败：球消耗
```

**示例**：已有一只「幼龙」(stack 1)，再抓到一只幼龙 → 自动合并为 stack 2，战力跳档，**不是** 栏里两只各算各的。

### 2.3 战力随数量跳档

`stackCount` 达到阈值时 `powerIndex` 跳升（配置 `pet-merge-power.json`）：

| stackCount | powerIndex | 战力示意 | UI 文案 |
|------------|------------|----------|---------|
| 1 | 0 | 基础 | 「幼体 ×1」 |
| 2 | 1 | +40% | 「合并 ×2」 |
| 3~4 | 2 | +80% | 「强化 ×3」 |
| 5~7 | 3 | +150% | 「精英」 |
| 8~11 | 4 | +250% | 「首领」 |
| 12+ | 5 | +400% | 「伪 Boss」 |

同种 Boss 宠 stack 到高位后，单只战力可接近真 Boss — **靠肝/靠球堆出来**。

### 2.4 跨档合成（可选，与 stack 并行）

部分种类在 `stackCount` 达 **固定值** 时 **进化换种**（仍无等级，只换 speciesId）：

```
pet_slime stack ≥ 5  → 进化为 pet_elite_slime，stack 重置为 1 但 powerIndex 保底 +2
pet_elite_slime stack ≥ 3 → pet_slime_king
```

进化后栏位仍占 1 格，继续靠数量叠。

## 3. 出战：后期五六只 Boss 打架（已确认方向）

| 阶段 | 最大出战数 |
|------|------------|
| 开局 | 1 只 |
| 回合 5+ | 2 只 |
| 回合 10+ | 3 只 |
| 回合 15+ / powerIndex 总和达标 | **最多 6 只** |

- 每只已出战宠物独立 AI：跟随、普攻、小技能
- 栏位上限 **12 格**（不同种类各占 1 格，同种只合并不占地）
- **终极目标感**：带着 **5~6 只合并满的 Boss 宠** 清场

```typescript
deployCap = min(6, baseDeploy + roundBonus + heroPassiveBonus)
```

---

## 4. 捕获流程

- **击杀后自动**判定，不手动扔球
- 球优先级：普通 → 高级 → 大师球（可配置「Boss 优先大师球」）
- 无球：提示，不判定
- 失败 **必消耗球**

### 4.1 能抓什么怪（种类档位，不是宠物等级）

`captureTierCap` 决定本局能抓的最高 `speciesTier`：

| cap | 可抓 |
|-----|------|
| 1 | normal |
| 2 | + elite |
| 3+ | + boss |

cap 不足：不消耗球，提示「需提升捕获档次」。

cap 来源：回合、局内属性（**luck**）、强化/附魔/武器养成、技能（见 [20-抓宠英雄设计](./20-抓宠英雄设计.md)）。

### 4.2 捕获率与大师球

```
最终率 = 基础率 × 球 × 技能 × (1 + linkageBonus(attack, luck, maxHp)) × 养成
```

- **attack + luck** 可叠；**maxHp + luck** 可叠；**luck=0 高攻** 仍高（见 [25 §2.5、§3.1](./25-属性系统设计.md)）
- 大师球 **非默认 100%**；需武器升级 + 强化 + 附魔堆满（见 v0.6 公式）

## 5. 职业门槛

仅 `archetype: 'capture'` 且 `canCapture: true`。其他英雄不触发捕获、球不可用。

---

## 6. StatSystem

```typescript
sourceId: `pet:${speciesId}:${slotIndex}`
// 属性 = PetSpeciesBase × powerIndexMultiplier(stackCount)
```

## 7. UI

- 合并时：两只图标合成动画 + 战力条跳升
- 栏内显示「×N」合并数，不显示 LV
- 出战位：最多 6 个宠物头像环绕英雄
