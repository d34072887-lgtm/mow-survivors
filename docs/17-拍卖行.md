# 17 — 拍卖行 Auction

[← 返回索引](./README.md) | 上级：[13-特殊场所总览](./13-特殊场所总览.md)

> **定稿 v0.6** — 简单竞价；被抢时 **买到的货没了**，还可能 **丢其他东西**。

---

## 1. 定位

竞拍稀有货；随机 **抢拍事件** — 钱花了货没了，甚至波及背包。

---

## 2. 基础流程

```
进入 → 展示 3 件拍品 → 竞价（15 秒）→ 最高价获得 → 离开
```

NPC 会跟价；玩家赢则扣金币拿货。

### 2.1 财富值隐藏拍品（已确认）

进入拍卖行时读 **最终 wealth**（见 [25 §2.5](./25-属性系统设计.md)）：

| wealth 阈值 | 解锁 |
|-------------|------|
| ≥ 100 | 第 4 件隐藏拍品（橙装碎片、保护石包等） |
| ≥ 180 | 替换 1 件普通拍品为 **传说池** 条目 |

配置：`data/configs/auction/hidden-pools.json`。

---

## 3. 抢拍事件（已确认）

### 3.1 类型 A：`bid_war` 竞价战

神秘买家加入，2~3 轮快速加价 — 价被顶高，**货还在**，只是买贵了。

### 3.2 类型 B：`instant_snatch` 直接抢夺（核心惩罚）

```
你已拍得 / 成交瞬间
  → 过场：「拍卖品被劫！」
  → **刚买到的那件道具 / 装备直接消失**（钱不退）
  → 额外 roll：背包 / 本次拍卖相关物品 **可能再丢 0~2 件**
  → 离开拍卖行或继续（若还有未成交拍品）
```

| 损失项 | 规则 |
|--------|------|
| **成交物** | **必没** — 你拍到什么，什么消失 |
| **已付金币** | **不退** |
| **连带损失** | 30% 再丢 1 件；15% 再丢 2 件 |
| **连带范围** | **背包道具 + 装备栏 6 格** 均可被劫（已确认 v0.7） |
| 装备丢失 | 该格装备整件消失（强化、附魔一并没了） |

设计意图：被抢 = **货没了 + 可能连装备都丢**，赌狗痛感明确。

### 3.3 触发与频率

| 项 | 建议 |
|----|------|
| `instant_snatch` 基础概率 | 8% / 每件成交 |
| 稀有拍品（保护石、大师球） | 概率 ×1.5 |
| 单次 visit | 最多 1 次 `instant_snatch` |
| `bid_war` | 可多次，只抬价不丢货 |

**被抢概率修正**（见 [25 §3.1](./25-属性系统设计.md)）：基础 `instant_snatch` + `auctionSnatchRate`(③) − **armor / wealth** 小幅减免。高防、有身家的 build 略安全，但不免疫。

---

## 4. UI 要点

- 成交后若触发抢夺：强演出 + 清单「丢失：XXX（已购）」「丢失：YYY（连带）」
- 通用提示：「拍卖存在被劫风险」
- **无默认保险**；后续可加高级「拍卖保险券」减连带损失（占位）
