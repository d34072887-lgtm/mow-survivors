# 18 — 配置与目录结构

[← 返回索引](./README.md)

## 代码目录（建议）

```
src/
├── core/                 # 循环、实体、场景
├── systems/              # stat, economy, random, round
├── modules/
│   ├── hero/
│   ├── monster/
│   ├── pet/
│   ├── treasure/
│   ├── map/
│   ├── equipment/
│   ├── item/
│   ├── attribute-pick/
│   ├── round-shop/
│   ├── spawn/
│   └── special-venue/
│       ├── casino/
│       ├── auction/
│       ├── enhance/
│       └── enchant/
├── ui/                   # 按场景拆分
├── data/configs/         # 见下表
└── runtime/              # 单局状态、存档
```

**原则**：模块间通过 `EventBus`、`StatSystem`、配置 ID 协作，不互相直接改内部状态。

## 配置文件一览

| 内容 | 路径 |
|------|------|
| 英雄 | `heroes/{id}.json` |
| 主动/被动技能 | `skills/active/`, `skills/passive/` |
| 普通/精英/Boss | `monsters/normal|elite|boss/{id}.json` |
| 宠物/合成 | `pets/`, `pet-synthesis.json` |
| 装备 | `equipment/{id}.json` |
| 武器 | `weapons/{id}.json` |
| 道具 | `items/stat|consumable|material/` |
| 刷怪/难度 | `spawn-rules/`, `difficulty-curve.json` |
| **属性注册表** | `stats/stat-registry.json` — 见 [25-属性系统设计](./25-属性系统设计.md) |
| 属性池 | `attribute-pools/` |
| 商店 | `shop/shop-pools.json` |
| 强化 | `enhance/` |
| 附魔 | `enchant/` — 见 [15-附魔台](./15-附魔台.md) |
| 挖宝 | `treasure/` |
| 特殊场所权重 | `venue-weights.json` |

所有配置带 `version` 字段，便于存档迁移。
