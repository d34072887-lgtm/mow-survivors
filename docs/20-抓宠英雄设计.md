## 1. 流派约束（所有抓宠英雄共用）

| 长板 | 短板（刻意做低） |
|------|------------------|
| **幸运值**（通用）；技能改捕获/合并 | 攻击、生存、移速 |

**不给**：高普攻、自保回血、单人割草能力。

---

## 2. 范例英雄 A：驯兽师「小葵」

> 入门抓宠 — 稳定捕获、合并收益高。

### 基础面板（相对输出英雄 = 100%）

| 属性 | 比例 |
|------|------|
| 攻击 | 58% |
| 生命 | 62% |
| 移速 | 90% |
| **幸运值** | 115%（相对输出英雄 = 100%） |

### 主动技能「诱捕标记」

- CD 12s：标记范围内怪物 3s，期间被击杀 **捕获判定 ×2**（技能倍率，非 StatId）
- 不造成伤害 — 纯功能

### 被动技能「羁绊合并」

- 同种宠物每次合并（stack +1）时，该宠 **额外 +8% 战力**（叠在 merge 表之上）
- 鼓励一直抓同一种往 Boss 堆

### 属性选择池

**幸运值**、捕获档次（`captureTierCap` 来自附魔/回合）、合并相关权重偏高；攻击 / 防御仍占池

### 设计备注

## 3. 范例英雄 B：虫王「皮囊」

> 进阶 — 多宠出战型，适合后期 6 Boss 宠海。

### 基础面板

| 属性 | 比例 |
|------|------|
| 攻击 | 52% |
| 生命 | 55% |
| 移速 | 85% |

### 主动技能「兽群冲锋」

- CD 18s：已出战宠物集体冲向目标点，造成 **宠物战力总和 ×30%** 的爆发伤害（唯一像样的输出手段）

### 被动技能「统御上限」

- 出战宠物上限 **+1**（比其他抓宠英雄多 1 格，更早达到 6 只）
- 昆虫/爬行类 `speciesId` 合并时 stack **+2**（抓 1 只当 2 只合并）

### 玩法 loop

前期苟活 → 狂抓虫系 → 快速 stack → 中期 4~5 只出战 → 后期 6 只精英/Boss 虫海。

## 4. 范例英雄 C：契约师「零」

> 赌狗型 — 捕获失败有补偿，成功有波动。

### 被动「赌徒契约」

- 捕获 **失败**：30% 概率不消耗精灵球
- 捕获 **成功**：20% 概率该种 `stackCount` **额外 +1**（一次捕获当两次合并）

### 主动「命运投掷」

- 下一击杀的捕获判定改为：50% 必成功但消耗 **双倍球** / 50% 正常判定

### 短板更明显

攻击 50%，生命 58% — 最脆的抓宠英雄，靠赌和堆量。

## 6. 与合并机制的关系

- 小葵：合并后单宠更强 → 适合 **少而精** 2~3 只满 stack Boss
- 皮囊：出战多 + 虫系双倍 stack → 适合 **6 只海**
- 零：赌双倍 stack → 极端 Boss 单宠或暴毙
