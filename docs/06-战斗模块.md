# 06 — 战斗模块 Battle

[← 返回索引](./README.md)

## 职责

- 局内自动战斗：移动、攻击、受击、死亡
- 回合计时，时间到 → `RoundEnded`
- 击杀 → 掉落、抓宠入口

## 回合时长

| 阶段 | 时长 |
|------|------|
| 前期 | ~15 秒/回合 |
| 递增 | 随回合增加 |
| 上限 | 60 秒/回合 |

配置：`RoundDurationConfig`
