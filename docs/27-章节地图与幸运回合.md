## 1. 一句话

每个地图章节约 **5 个连续回合**（爬塔刷图）；加载时系统已定好其中 **1 个回合是幸运回合**。玩法仍是限时刷怪 + 捡物资；幸运回合更难、奖励更偏养成，失败不罚。长期深度在 **装备 / 宠物 / 宝石 → 多流派**（详见 28）。第一章可能需**反复刷约十来次**才第一次打过 BOSS；内容扩展以**地图推进**为主，不以「通关解锁难度档」为主。

---

## 2. 已确认

### 2.1 章节结构

| 项 | 约定 |
|----|------|
| 地图示例 | 翠绿草场、余烬高地（后续可扩展） |
| 一章体量 | 大约 **5 回合**（沟通时称「5 关」） |
| 推进方式 | **只要不死，时间到 → 自动进入下一回合** |
| 体验定位 | **爬塔养成**：不是一上来就能打过本章 BOSS；靠刷图爆装备、爆宠物、升级，慢慢养到能打 BOSS |

### 2.2 幸运回合（神秘 / 彩蛋回合）

| 项 | 约定 |
|----|------|
| 何时定下 | **进关卡加载时系统已定义好**（哪一回合是幸运回合） |
| 数量感 | 每个地图章节 **有机会随机刷出 1 个** 幸运回合（夹在约 5 回合里） |
| 玩法 | **与普通回合同一套**：固定时间内刷怪数量 + 捡到物资数量；**不做**地下城式传送区 / 另进门 |
| 难度 | **偏难**（隐藏关向）：现阶段打不过正常；多刷、在 BOSS 处拿优质资源成长后，再回来打更合适 |
| 失败 | **不处罚**（鼓励试探，不卡死进度） |
| 奖励方向 | 偏 **角色成长辅助**：宠物、装备、金币、钻石等；前期幸运关也可 **极低概率** 开出后期装/材料、无级别限制、自带特级装（见 28） |
| 再进同一章 | **每次进章幸运位置建议重抽**（反复刷不腻） |

### 2.3 养成与流派（长期方向）

| 项 | 约定 |
|----|------|
| 养成主轴 | 装备、宠物，以及 **宝石类** 等可搭配素材 → 细则 [28](./28-养成装备与宠物合宠.md) |
| 深度放在哪 | 关卡结构保持简单；深度来自掉落组合 → **多种流派** |
| 与幸运回合关系 | 幸运回合是养成加速点 / 高难宝藏房，不是另一套操作玩法 |
| 进度手感 | **养成副本**：可反复进同一章；通关不是毕业；丰富度跟地图走 |

## 3. 和现有文档的关系

- 局内「战斗回合 → 属性选择 → 商店 → …」循环仍见 [01-游戏流程](./01-游戏流程.md)。
- 本文描述的是 **地图章节层**：选地图后，本章内约 5 回合的骨架 + 幸运回合规则。
- 特殊场所（赌场 / 拍卖等，见 [13](./13-特殊场所总览.md)）与幸运回合 **不是同一概念**：幸运回合仍是战斗回合，只是难度与奖励不同。

## 4. 仍待定（下一轮沟通）

| 话题 | 说明 |
|------|------|
| 幸运回合在 1～5 的位置分布 | 完全随机，还是偏中后段？ |
| 打不过时能否跳过继续后面回合 | 必须碰到并试完，还是可绕过？ |
| 再次进入同一章节 | 幸运位置 / 奖励类型是否重抽？ |
| BOSS 位置 | 5 回合之后单独一关，还是第 5 回合即 BOSS？ |
| 幸运奖励类型 | 固定一种（本回合就是宠物关），还是进关前随机抽类型？ |
| 宝石系统 | 只镶装备，还是宠物也可用？细则另开文档 |
| 与「第 5 回合起特殊场所」 | 是否并存、如何避冲突 |
