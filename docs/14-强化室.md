# 14 — 强化室 EnhanceRoom

[← 返回索引](./README.md) | 上级：[13-特殊场所总览](./13-特殊场所总览.md)

> **定稿 v0.6** — DNF 式刺激手感；橙装高段可碎装；保护石必提醒；强化仅本局有效。

---

## 1. 定位

消耗 **强化石** 提升装备 **强化等级**（+1、+2…），增加 **白值属性**。

**在整体装备体系中的位置：辅。** 装备的主要成长点在 **附魔**（见 [15-附魔台](./15-附魔台.md)、[07-装备模块](./07-装备模块.md)）。强化负责 DNF 式数值赌博，不是 build 方向的主来源。

| | 强化室（辅） | 附魔台（**主**） |
|--|-------------|------------------|
| 消耗 | 强化石 + 保护石 | 附魔石 + 保护符 |
| 改什么 | `enhanceLevel` 白值 | **词条 Affix**（build 核心） |
| 风险 | 掉级 / 碎装 | 覆盖好词条 |
| 玩家目标 | 「再 +1 攻」 | 「这条词条打对了没」 |

---

## 2. 设计目标：刺激感

强化要有 **DNF 式心跳**，不是无声无息改数字：

| 手段 | 说明 |
|------|------|
| 结果演出 | 成功：金光 / 音效；失败：碎裂声；掉级：等级数字往下跳 |
| 风险预览 | 确认前展示：**成功率、失败后果（掉级 / 碎装）** |
| 碎装倒计时 | 橙装高段已失败 1 次 → 大红字 **「再失败 1 次将碎装！」** |
| 保护石提醒 | +8 以上未勾选保护石 → **强制二次确认** + 文案「使用保护石可避免掉级/碎装」 |
| 高段动效 | +10 以上尝试时屏幕轻震、进度条慢速 suspense |

---

## 3. 强化规则

### 3.1 等级上限（按品质）

| 品质 | 最高强化 |
|------|----------|
| 白 | +7 |
| 绿 | +9 |
| 蓝 | +11 |
| 紫 | +12 |
| 橙 | +15 |

**强化等级仅本局有效** — 局结束 `enhanceLevel` 归零，与附魔一致。

### 3.2 成功率与失败后果

| 目标等级 | 基础成功率（参考） | 无保护石失败后果 |
|----------|-------------------|------------------|
| +1 ~ +7 | 90% → 60% | **仅消耗强化石**，等级不变 |
| +8 ~ +10 | 50% → 30% | **掉 1 级** |
| +11 ~ +12 | 25% → 15% | **掉 1 级** |
| +13 ~ +15（橙） | 10% → 5% | **掉 1 级**；且累计 **连续失败 2 次 → 碎装** |

**最终成功率** = 表值 + `enhanceSuccess`(③) + **linkageBonus(attack, luck, critRate)** — luck=0 高攻仍可成（见 [25 §3.1](./25-属性系统设计.md)）。

### 3.3 结果类型

| 结果 | 效果 |
|------|------|
| `SUCCESS` | level +1，强化石 -1 |
| `FAIL_KEEP` | +7 及以下失败；或 **使用了保护石** |
| `FAIL_DOWNGRADE` | +8+ 失败且无保护石 → level -1 |
| `FAIL_BREAK` | 橙装 +13~+15 **连续第 2 次**失败且无 **高级保护石** → **装备销毁** |

**强化石必定消耗**；勾选保护石时保护石也消耗。

### 3.4 碎装计数

```typescript
equipment.runState = {
  enhanceLevel: number
  consecutiveFailCount: number   // 橙装 +13 以上失败 +1，成功或保护后归零
}
```

- 仅 **橙装** 且目标 **+13 以上** 时累计
- 使用 **高级保护石**：失败时 **不计入** 碎装计数，且不掉级
- 使用 **普通保护石**：不掉级，但 **仍计入** 碎装计数（第二次仍可能碎）

---

## 4. 保护石（必提醒）

### 4.1 规则

| 类型 | 效果 |
|------|------|
| **普通保护石** | 失败 **不掉级**；橙装高段仍计碎装次数 |
| **高级保护石** | 失败 **不掉级 + 不计碎装 + 不碎装** |

### 4.2 UI 提醒（已确认必须做）

| 场景 | 提醒 |
|------|------|
| +8 以上未勾选保护石 | 弹窗：「失败可能掉级，使用 **保护石** 可保护等级」 |
| 橙装 +13+ 且 `consecutiveFailCount === 1` | 全屏警告 + 推荐高级保护石 |
| 碎装后 | 明确文案「装备已损毁，下次记得带保护石」 |

> 附魔侧对应道具为 **保护符**（见 [15-附魔台](./15-附魔台.md)），UI 勿混称；强化室只提 **保护石**。

---

## 5. 流程

```
进入强化室 → 选装备 → 选强化石
  →（+8+）勾选保护石？系统根据风险等级提醒
  → 预览成功率 / 失败后果 / 碎装倒计时
  → 确认 → 刺激演出 → 结算
```
