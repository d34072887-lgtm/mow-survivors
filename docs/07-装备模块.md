# 07 — 装备模块 Equipment

[← 返回索引](./README.md) | 武器专文：[23-武器设计](./23-武器设计.md)

## 规则（已确认）

| 规则 | 说明 |
|------|------|
| 栏位上限 | **6 格** |
| **6 格全武器** | 与土豆兄弟一致，**6 格均可且通常为武器**；生存靠 **道具** 叠层，不另设护甲槽 |
| 合成 | **2 件同 ID + 同品质** → 1 件 **同 ID** 更高品质 |
| 叠加 | 占 1 格，不可像道具那样叠 count |

### 合成示例

```
2× 胡椒冲锋枪（蓝）  →  1× 胡椒冲锋枪（紫）
2× 胡椒冲锋枪（紫）  →  1× 胡椒冲锋枪（橙）
```

不同 ID 的武器 **不能** 互相合成。

## 装备成长：附魔为主，强化为辅（已确认）

```
六把武器  →  同 ID 合成升品质（开附魔槽）
         →  【主】附魔打词条（build 核心，见 [15-附魔台](./15-附魔台.md)）
         →  【辅】强化 +N 白值（DNF 赌风险，见 [14-强化室](./14-强化室.md)）
         →  局内金币升级（小补）
```

| 途径 | 定位 | 玩家感知 |
|------|------|----------|
| **附魔** | **主要变强点** | 词条决定 build 方向；打书覆盖是核心赌狗 |
| **强化** | 次要、偏数值 | 提白值；碎装风险；有保护石 |
| 合成升品质 | 开更多附魔槽 | 橙装 5 槽 = 附魔空间大 |
| 局内升级 | 小钱平滑 | 本局有效 |

> 设计意图：**装备的上限更多来自「附魔词条怎么打」**，而不是纯堆强化等级。

## 品质与词条槽

白 1 / 绿 2 / 蓝 3 / 紫 4 / 橙 5 槽（附魔见 [15-附魔台](./15-附魔台.md)）

**附魔词条、强化等级均仅本局有效**。
