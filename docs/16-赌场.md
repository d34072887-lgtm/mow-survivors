## 1. 定位

简单快速赌金币；**赢太多** 触发隐藏关 **赌场打手** — 难打，但 **打赢有奖励**。

---

## 2. 基础玩法

### 比倍率（第一版主推）

```
下注 N → 50% 得 2N / 50% 亏 N
```

规则 3 秒内能出结果，不复杂。

### 2.1 财富值隐藏赌桌（已确认）

进入赌场时读 **最终 wealth**（见 [25 §2.5](./25-属性系统设计.md)）：

| wealth 阈值 | 解锁 |
|-------------|------|
| ≥ 80 | 高倍比倍率桌（如 3× / 5×，胜率略低） |
| ≥ 150 | 隐藏转盘 / 连环赌局（占位，首版可只做 1 档） |

未达阈值只显示基础比倍率；**高财富低攻击** 仍可能死在打手关。

### 2.2 赌场负面 debuff — 多属性联动（已确认）

赌桌除比倍率外，可 roll **负面 debuff**（下回合攻速 -X%、移速 -X%、扣金币等）。

**触发率与强度** 读 [25 §3.1](./25-属性系统设计.md)：

```typescript
debuffChance = baseChance × (1 - attack×A - maxHp×H - luck×L)
debuffPower  = debuffBase × (1 - maxHp×H2 - attack×A2)
```

| stat 高 | 效果 |
|---------|------|
| **attack** | 负面 debuff **更不易触发**、**持续时间更短** |
| **maxHp** | 触发率 ↓；若触发，**强度减弱**（扣血类减伤） |
| luck | 仅 **小幅** 降触发率；**主责仍是正面奖池权重**，不包办 debuff |

**设计意图**：**大力出奇迹** — 高 attack/maxHp 少被坑；纯堆 luck 有 cap，不能碾压战斗 build。

## 3. 打手触发：按回合动态阈值（已确认）

**不用固定 500 金** — 后期 500 太轻松。阈值随 **当前回合数** 缩放：

```typescript
enforcerThreshold = basePerRound × currentRound × difficultyMultiplier
// 例：basePerRound = 80
// 回合 3：240 金净赢触发
// 回合 10：800 金净赢触发
// 回合 20：1600 金净赢触发
```

配置表 `enforcer-trigger.json`：

```json
{
  "basePerRound": 80,
  "minThreshold": 150,
  "maxThreshold": 5000,
  "consecutiveWinsTrigger": 5,
  "triggerMode": "netProfit OR consecutiveWins"
}
```

| 条件 | 说明 |
|------|------|
| 本次赌场 **净赢 ≥ enforcerThreshold** | 主触发 |
| 或 **连赢 ≥ 5** | 副触发（手气太顺） |

同一次进赌场最多触发 **1 次**，不可回避。

## 4. 打手隐藏关

```
触发 → 过场「赌场打手来了！」
  → 特殊战斗（30~45s，难度高于当前回合）
  → 战胜：奖励 + 安全离开
  → 战败：扣本次赌场净赢一定比例后离开
```

### 4.1 难度

- 按 `currentRound` + 本次 `netProfit` 缩放打手 HP / 伤害
- 独立怪物：`monsters/elite/casino-enforcer.json`

### 4.2 战胜奖励（已确认：要有）

不是空跑，**打赢打手给小奖励**：

| 奖励类型 | 建议 |
|----------|------|
| 金币 | 净赢的 **30%~50%** 额外奖金，或固定 `round × 50` |
| 道具 | 低概率掉保护石 / 高级球 / 赌场所需消耗品 |
| 成就感 | 本局首次击败打手额外 +1 次商店刷新（可选） |

```typescript
enforcerVictoryReward = {
  gold: Math.max(netProfit * 0.4, currentRound * 50),
  bonusItemPool: 'casino-enforcer-loot'
}
```

### 4.3 战败惩罚

- 扣除本次赌场 **净赢的 50%**（没净赢则扣固定 `round × 20`）
- 然后强制离开赌场
