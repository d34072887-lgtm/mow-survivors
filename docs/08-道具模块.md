## 规则（已确认）

- 道具 **可无限叠加**（同 ID 合并 `stackCount`）
- 与装备栏分离，不占 6 格装备位

## 职责

- **品阶**：普通 / 中级 / **高级** / **极品** — 越高机制越强，**高级/极品不必绑职业**
- **条件触发**：如生命 ≥500 → 移速 +X（按流派 build 设计）
- **纯叠层** `perStack` + **条件** `conditional` + **跨流派偷师** `archetypeBridge`
- 材料、消耗品、赌狗副作用

见 **[24-道具设计](./24-道具设计.md)** §1.1、§3.4、§6.9。
