# 15 — 附魔台 EnchantRoom

[← 返回索引](./README.md) | 上级：[13-特殊场所总览](./13-特殊场所总览.md)

> **开发必读**：附魔只有两种结果——**新增词条**或**覆盖词条**。不存在「失败不变」。

---

## 1. 设计定位

附魔台 = 给装备打词条（Affix）的赌狗系统。

**在整体装备体系中的位置：主。** 六把武器的上限，更多取决于 **附魔槽里有什么词条**；强化只是辅（见 [14-强化室](./14-强化室.md)、[07-装备模块](./07-装备模块.md)）。

- 品质越高 → 附魔槽越多（橙 5 槽）→ 附魔空间越大
- 打书（新增 / 覆盖）是本作装备 **最核心的赌狗与 build 决策**

**已确认的核心规则：**

| 规则 | 说明 |
|------|------|
| 只有两种结果 | **新增一条词条**（没盖掉旧的）或 **盖掉一条旧词条**（随机覆盖） |
| 不存在失败 | 没有「附魔失败、装备不变」这种结果 |
| 必消耗附魔石 | 只要成功发起附魔，附魔石 **必定 -1** |
| 附魔本局有效 | 附魔产生的词条 **仅本局有效**，局结束清除（装备本体可带出，附魔词条不保留） |
| 满槽 + 普通石 | **必然**随机覆盖一条未锁定词条 |
| 保护符 | 可以有，但必须是 **高级道具**（见 §6） |

---

## 2. 核心概念

### 2.1 装备词条槽 AffixSlot

词条槽数量由装备品质决定：

| 装备品质 | 词条槽数 |
|----------|----------|
| 白 | 1 |
| 绿 | 2 |
| 蓝 | 3 |
| 紫 | 4 |
| 橙 | 5 |

```typescript
type AffixSlot = {
  index: number
  affixId: string | null   // null = 空槽
  locked: boolean          // 金币锁定，防随机覆盖
}
```

### 2.2 词条 Affix

```typescript
type AffixConfig = {
  id: string
  name: string
  tier: "common" | "rare" | "epic" | "legendary"
  modifiers: StatModifier[]
  tags?: string[]
}
```

词条挂在本局运行时装备实例上；局结束随 run state 清除。

### 2.3 附魔石 EnchantStone

```typescript
type EnchantStoneConfig = {
  id: string
  name: string
  tier: 1 | 2 | 3 | 4
  affixPoolId: string
  allowTargetSlot: boolean   // 满槽时能否指定覆盖哪一格（高品阶）
  canReplaceLocked: boolean    // 指定覆盖时能否覆盖已锁定槽（默认 false）
}
```

**品阶能力（已确认 / 默认值）**

| 品阶 | 名称 | 有空槽时 | 满槽时 |
|------|------|----------|--------|
| 1 | 普通附魔石 | **必定新增**（写入随机空槽） | **必定随机覆盖**（未锁定槽中等概率） |
| 2 | 高级附魔石 | 必定新增 | 必定随机覆盖；词条池品质更高 |
| 3 | 史诗附魔石 | 必定新增 | 随机覆盖 **或** 玩家指定槽覆盖 |
| 4 | 传说附魔石 | 必定新增 | 玩家指定槽覆盖 |

> 普通石没有成功率百分比，没有失败分支。

## 3. 玩家操作流程

```
进入附魔台
  → 选 1 件装备
  → 选 1 颗附魔石
  →（可选）花金币锁定词条槽
  →（可选）使用保护符（仅当有空槽时可用，见 §6）
  →（史诗/传说 + 满槽）选指定覆盖槽位
  → 确认附魔 → 结算（必消耗附魔石）→ 返回
```

---

## 4. 附魔结算状态机（开发按此实现）

### 4.1 前置检查

| 检查 | 不通过时 |
|------|----------|
| 已选装备 + 附魔石 ≥ 1 | 按钮禁用 |
| 满槽且 `replaceableSlots` 为空（全锁定） | 按钮禁用，提示解锁；**不消耗石** |
| 使用保护符但无空槽 | 保护符按钮禁用 |

### 4.2 判定分支（无失败分支）

```
开始附魔 → 附魔石 -1（此时已消耗，不可退回）

计算：
  emptySlots      = affixId === null 的槽
  replaceableSlots = affixId !== null 且 locked === false 的槽

若 emptySlots.length > 0：
  → 结果 ADD_TO_EMPTY（新增，不覆盖任何旧词条）

否则（满槽）：
  若玩家使用史诗/传说石且已选 targetSlot：
    → 结果 REPLACE_TARGET（覆盖指定槽）
  否则：
    → 结果 REPLACE_RANDOM（从未锁定槽中等概率随机选一个覆盖）
```

**两种结果对照（给用户看的文案）**

| 结果类型 | 玩家感知 |
|----------|----------|
| `ADD_TO_EMPTY` | 没盖掉旧的，**新增了一条**词条 |
| `REPLACE_RANDOM` / `REPLACE_TARGET` | **盖掉了**一条旧的，换成新的 |

### 4.3 ADD_TO_EMPTY（新增）

- 从附魔石词条池随机 1 条词条
- 写入 `emptySlots` 中随机一个空槽
- **不修改**任何已有槽位
- 事件：`EnchantResult { type: "ADD_TO_EMPTY", slotIndex, newAffixId }`

### 4.4 REPLACE_RANDOM（随机覆盖）

- 从 `replaceableSlots` 等概率选 1 槽
- 旧词条移除，新词条写入
- 锁定槽 **绝不会** 被选中
- 事件：`EnchantResult { type: "REPLACE_RANDOM", slotIndex, oldAffixId, newAffixId }`

### 4.5 REPLACE_TARGET（指定覆盖）

- 仅史诗/传说石 + 玩家已选槽位
- 只覆盖该槽（默认不可覆盖 locked 槽）
- 事件：`EnchantResult { type: "REPLACE_TARGET", ... }`

### 4.6 全槽锁定

- 满槽且全部 locked → **不允许附魔**，附魔石不消耗

---

## 5. 词条锁定（金币）

| 规则 | 说明 |
|------|------|
| 作用 | 该槽不会被 `REPLACE_RANDOM` 选中 |
| 费用 | 第 1 条 50 金，第 2 条 100 金（可配置） |
| 上限 | 每件装备最多同时锁 2 条 |
| 持久 | **本局内**有效；局结束清除锁定（附魔词条也清除） |

锁定防随机覆盖，不防史诗/传说 **指定槽覆盖**（若配置 `canReplaceLocked`）。

---

## 6. 保护符（高级道具）

**定位**：稀有高价道具，不是常规消耗品。

| 项 | 规则 |
|----|------|
| 获取 | 商店低概率刷新、拍卖行、赌场大奖等；**不在普通商店常驻** |
| 使用条件 | **必须仍有空槽**；满槽时按钮灰色（满了只能赌覆盖，保护符帮不上） |
| 效果 | 本次附魔 **强制走 ADD_TO_EMPTY**，保证只新增、不覆盖 |
| 消耗 | 保护符 -1，且附魔石 -1（两者都消耗） |
| 与锁定关系 | 保护符替代「赌覆盖」的风险；锁定是防覆盖的另一种手段 |

```typescript
type ProtectionTalismanConfig = {
  id: string
  tier: "epic" | "legendary"   // 至少史诗档，体现高级
  shopWeight: number           // 极低
  price: number                // 明显高于普通道具
}
```

| 内容 | 局内 | 局外 |
|------|------|------|

| 附魔词条 | ✅ | ❌ 清除 |
| 词条锁定状态 | ✅ | ❌ 清除 |

## 8. 词条去重

同装备不允许两条相同 `affixId`。池子抽到重复 → 重 roll，最多 3 次；仍重复则换同 tier 其他词条。**不出现失败不变。**

## 10. 示例场景

### A：有空槽 — 只新增

- 蓝装：`[攻击+10, 空, 空]` + 普通石
- 结果：`[攻击+10, 暴击+5%, 空]` — **没盖掉**，新增暴击

### B：满槽 — 必然盖掉一条

- 紫装 4 槽全满、未锁定 + 普通石
- 随机选中暴击槽 → 换成防御
- **盖掉了**暴击 — 这是赌点

### C：锁定 + 满槽

- 锁定攻击槽后，覆盖只在其余 3 槽中随机

### D：保护符 + 有空槽

- 使用保护符 + 普通石，强制 ADD_TO_EMPTY
- 即使未来扩展了其他逻辑，本次也保证不覆盖

### E：局结束

- 所有附魔词条清空，下局装备恢复为未附魔白值状态
