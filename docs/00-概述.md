# 00 — 项目概述

[← 返回索引](./README.md)

## 游戏类型

幸存者类 / 割草游戏（Bullet Heaven）：

- 局内自动战斗，玩家主要负责走位与回合间决策
- 局内按**时间回合**推进，回合间成长、购物、随机事件
- 局外以英雄、装备、道具池为核心，持续扩展

## 核心体验：赌狗养成系

不是「一上来就割草」的无脑爽游，而是 **有风险、有取舍、有养成路径**：

| 维度 | 设计意图 |
|------|----------|
| 前期有压力 | 第 1 回合怪物少、时间短，英雄也弱 |
| 中后期才爽 | 属性、商店、合成、抓宠、赌场等叠出来的强 |
| 赌性 | 刷新属性、附魔打书、赌场、挖宝都有概率博弈 |
| 流派分化 | 叠血、挖宝、抓宠等路线不同，英雄长短板明显 |

**目标体验**：每回合都在赌「刷不刷、走哪条路」，不是挂机过关。

## 设计目标

| 目标 | 说明 |
|------|------|
| 模块化 | 英雄、怪物、数值、装备、道具、地图、场所各自独立 |
| 数据驱动 | 新内容以配置为主，少改核心代码 |
| 可长期更新 | 配置 + 插件注册接入新内容 |
| 网页端 | **竖屏手机浏览器**可玩（见 [26-手机版美术与界面约定](./26-手机版美术与界面约定.md)） |
