# 04 — 怪物模块 Monster

[← 返回索引](./README.md)

## 职责

- 普通怪、精英怪、Boss 模板定义
- **三类分目录、分文件**，按 ID 调用，数值不混

## 文件结构

```
data/configs/monsters/
├── normal/           # slime.json, bat.json …
├── elite/            # elite-orc.json …
├── boss/             # boss-dragon.json …
└── index.json        # id → 路径、分类
```

## 三类差异

| 类型 | 出现方式 | 配置侧重 |
|------|----------|----------|
| 普通怪 | 每回合刷怪池随机 | 数量多、单体弱、可捕获 |
| 精英怪 | 中后期按概率混入 | 血量高、词缀、好掉落 |
| Boss | 固定回合或里程碑 | 阶段技能、稀有掉落 |

## 单怪配置（草案）

```typescript
MonsterConfig {
  id: string
  category: 'normal' | 'elite' | 'boss'
  baseStats: StatBlock
  aiType: string
  drops: DropTableRef[]
  capturable?: boolean
  captureRate?: number
  petEvolveId?: string
}
```
