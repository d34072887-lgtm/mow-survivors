# 02 — 核心系统（跨模块共用）

[← 返回索引](./README.md)

以下系统被多个玩法模块依赖，**所有模块只通过这里改数值、发事件**。

---

## StatSystem 数值系统

> **属性全表、正负含义、影响链路** → 必读 **[25-属性系统设计](./25-属性系统设计.md)**。  
> 设计英雄 / 道具 / 附魔词条前，先查 StatId 是否已注册。

### 职责

- 统一管理全部 StatId（生存 / 输出 / 机动 / **幸运·财富** / 经济 / 强化附魔 / 赌狗场所）
- **英雄 base 仅通用属性**；全环节读 18 条 + **plateau 多通道联动**（见 25 §2.5）
- 来源：英雄 base、6 武器、道具、局内 4 选 1、附魔、强化、宠物、Buff
- Modifier：`flat` / `percent` / `multiply`；带来源 `sourceId`

### 公式

```
最终值 = clamp( (基础值 + Σflat) × (1 + Σpercent) × Πmultiply , min, max )
```

### 铁律

1. **单一入口**：只通过 `StatSystem.addModifier()` 改属性  
2. **分表存储**：各模块配置只写 StatId + 数值，不算最终值  
3. **增益 vs 风险**：`polarity: benefit | risk` — 风险型正数=更坑（见 25 文档 §3）

## RoundScheduler 回合调度

- 当前回合数、单回合时长（15s → 60s 上限）
- 驱动：战斗 → 属性选择 → 商店 → 特殊场所 → 下一回合

---

## Economy 经济

- 局内金币、刷新定价、商店价格
- **全环节** 读 18 主属性 **并列 capped 联动**（见 [25 §2.5](./25-属性系统设计.md)）
- **财富值** → 回合结束金币、隐藏池
