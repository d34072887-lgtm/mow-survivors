# 09 — 属性选择 AttributePick

[← 返回索引](./README.md)

## 触发

每个战斗回合结束后，**进入商店之前**。

## 规则（已确认）

1. 随机展示 **4 个**属性选项（血量、暴击、攻击等）
2. 玩家 **4 选 1**
3. 可 **刷新**，消耗金币，**每次刷新加价**

## 子模块

| 模块 | 职责 |
|------|------|
| `AttributePool` | 条目、权重、数值范围 |
| `AttributeRoller` | 抽 4 个、去重、保底 |
| `RefreshPricing` | 底价、递增公式 |

属性池与英雄绑定：`attributePoolId`（见 [03-英雄](./03-英雄模块.md)）。

可选 StatId 与档位见 **[25-属性系统设计 §9](./25-属性系统设计.md)**（如 attack、maxHp、armor、**luck**、**wealth**…）。

## 配置

```
data/configs/attribute-pools/{id}.json
data/configs/attribute-pick/refresh-pricing.json
```
