# 24 — 道具设计 Item

[← 返回索引](./README.md) | 武器：[23-武器设计](./23-武器设计.md) | 属性：[25-属性系统设计](./25-属性系统设计.md) | 模块：[08-道具模块](./08-道具模块.md)

> **定稿 v1.4** — 无限叠加、**线性 perStack**；高级/极品走 **条件触发**；**道具可让任意英雄偷师其他流派**；StatId 对齐 18 主属性。

---

## 1. 道具 vs 武器

| | 道具 | 武器（6 格） |
|--|------|--------------|
| 栏位 | **无限叠加** | 6 格 |
| 作用 | 18 属性 modifier、条件、材料 | 攻击模式 + 白值 + 附魔 |
| 生存 | **主要来源**（maxHp、armor、吸血） | 不管生存 |
| 赌狗 | 诅咒副作用、场所联动 | 少量 gambleSideEffect |

**分工**：附魔定装备 build；道具定 **怎么叠 18 属性、满足什么条件突然变强**，以及 **是否偷师别的流派**。

### 1.1 英雄定起点，道具定终局身份

| 层 | 管什么 | 不管什么 |
|----|--------|----------|
| **英雄** | 长板方向、技能、属性 4 选 1 权重 | 成套解法；**技能不跨流派** |
| **道具** | 任意 18 属性叠层、条件爆发、**跨流派能力切片** | 替代武器攻击模式 |
| **武器** | 6 格输出模式 | 生存、抓宠、挖宝 |

```
抓宠英雄 + 泰坦之心 + 铁餐盘  →  本局当血牛打
输出英雄 + 兽项圈 + 普通球    →  浅玩宠物流
挖宝英雄 + 胡椒冲锋枪×6      →  战斗也能割草
```

> **流派很多，但没有「专属道具锁」** — 只有 **本家加成（archetypeFit）** 与 **偷师道具（archetypeBridge）** 的效率差，玩家用商店组合决定这局到底是谁。

---

## 2. 品阶

| 品阶 | `tier` | 设计 |
|------|--------|------|
| 普通 | `common` | 纯 `perStack` 线性 |
| 中级 | `uncommon` | 小数值 / 单 tag |
| 高级 | `rare` | **条件触发** 为主 |
| 极品 | `legendary` | 强条件或多 stat 联动 |

> **不做** 3/6/9 层数里程碑；变强靠叠层 + 换更高档道具。  
> 高级/极品 **不必绑死英雄流派** — 按 build 条件设计。  
> **跨流派**靠 `archetypeBridge` 偷师，不靠英雄自带第二套技能。

## 3. 效果类型

### 3.1 纯叠层 `perStack`

```typescript
perStack: StatModifier[]   // 每层 +3% 攻速
```

### 3.2 条件触发 `conditional`

```typescript
conditional: {
  condition: ConditionRule
  modifiers: StatModifier[]
  perStackBonus?: StatModifier[]   // 每多 1 层，满足时额外加成
}
```

| 条件 type | 示例 |
|-----------|------|
| `hp_max_gte` | 生命 ≥500 → 移速 +8% |
| `hp_percent_lte` | 残血 → 攻速 +15% |
| `luck_gte` / `wealth_gte` | 幸运/财富达标 |
| `attack_gte` / `maxHp_gte` | 大力/血牛 build 门槛 |
| `affix_count_gte` | 附魔流 |
| `weapon_tag_count` | 6 格 burst 武器 ≥4 |
| `weapon_pattern_unique_gte` | 6 格武器攻击模式种类 ≥N |
| `armor_gte` / `dodge_gte` / `critRate_gte` | 防御/闪避/暴击 build 门槛 |
| `gold_gte` | 当前持有金币 |
| `wealth_lte` | 财富值 ≤ N（穷鬼 build） |
| `enhance_level_sum_gte` | 6 武器强化等级总和 |
| `all` | 多条件 AND（复合极品用） |
| `item_stack_gte` | 某道具自身叠层 ≥ N |
| `venue_active` | 当前在特殊场所（treasure / casino 等） |

### 3.3 诅咒 `curse`

强 `perStack` 正面 + `gambleSideEffect` 或负 modifier（risk stat 红字）。

### 3.4 本家契合 `archetypeFit` vs 跨流派偷师 `archetypeBridge`

| 字段 | 给谁 | 设计意图 |
|------|------|----------|
| `archetypeFit` | **本流派英雄** | 同路线更高效；鼓励「正统 build」 |
| `archetypeBridge` | **非本流派英雄**（或全员但外人更强） | 用道具 **借到别的流派的一小块能力** |

```typescript
// 本家：抓宠英雄叠层翻倍
archetypeFit?: {
  heroArchetype: 'capture' | 'dig' | 'tank' | 'dps' | 'gambler' | 'enchant' | 'enhance'
  perStackMultiplier: number
}

// 偷师：非 capture 英雄才（或更强）生效
archetypeBridge?: {
  targetArchetype: 'capture' | 'dig' | 'tank' | 'dps' | 'gambler' | 'enchant' | 'enhance'
  outsiderOnly?: boolean       // true = 仅 hero.archetype ≠ target 时生效
  outsiderMultiplier?: number  // 偷师倍率，默认 1
  nativeMultiplier?: number    // 本家倍率，默认 0.5（防本家无脑叠偷师件）
  perStack?: StatModifier[]
  conditional?: ConditionalBlock
}
```

**偷师给什么**（只用 18 属性 + ③ Build，禁止 captureRate/digRare）：

| targetArchetype | 道具借到的「能力切片」 | 典型 modifier |
|-----------------|------------------------|---------------|
| `capture` | 浅玩宠物流 | luck、petDamage、petMergeBonus、maxPetDeploy |
| `dig` | 浅玩挖宝经济 | wealth、luck、goldGain |
| `tank` | 当回合肉盾 | maxHp、armor、damageReduction、hpRegen |
| `dps` | 补输出 | attack、critRate、critDamage、attackSpeed |
| `gambler` | 敢进赌场/拍卖 | luck、wealth、casinoWinRate、auctionSnatchRate |
| `enchant` | 附魔更好出词 | luck、enchantRareWeight |
| `enhance` | 强化更敢点 | enhanceSuccess、enhanceBreakRisk |

**通用 stat 道具**（铁餐盘、过浓咖啡）不算偷师 — 谁都能叠；**带 `archetypeBridge` 的才算「借流派」**，tooltip 标「偷师：抓宠」等。

---

## 4. Tag 与武器

- 道具 `tags` 与武器 `tags` 一致时，**perStack 线性**作用于匹配武器（攻速、伤害系数等，见各道具说明）
- **无里程碑**；同 tag soft cap 可选（`tag-caps.json`，如单 tag 攻速合计 ≤80%）

---

## 5. StatId 规则（必读 25）

| ✅ 可用 | ❌ 禁止 |
|---------|---------|
| 18 主属性：attack, maxHp, luck, wealth, critDamage… | captureRate, digRare |
| ③ Build：enhanceSuccess, auctionSnatchRate… | 英雄专用玩法 stat |

抓宠 / 挖宝 / 强化 / 商店 → 叠 **luck、attack、maxHp、wealth** 等，由 [25 §3.1 linkage](./25-属性系统设计.md) 进玩法。
