> **定稿 v0.7** — 赌事件产出；战斗弱；与商店/强化/附魔联动。

---

## 1. 定位

**挖宝流派**专属玩法：用局内金币或铲子赌 **随机地层事件**，产出装备、金币、石头、球等。

挖宝英雄 **攻击、血量、生存明显偏弱**（见 [03-英雄](./03-英雄模块.md)），靠挖出来的东西滚雪球，再靠装备补战力。

---

## 2. 触发时机

| 时机 | 说明 |
|------|------|
| **回合商店阶段** | 挖宝英雄多一个「去挖宝」按钮（不进战斗） |
| **特殊场所** | 可随机进「遗迹层」专用 UI（与赌场并列，权重低） |
| **战斗内（被动）** | 部分英雄被动：击杀后小概率地上出宝箱点，走位拾取触发 |

第一版建议：**商店阶段主挖宝** + 被动偶发，逻辑清晰。

---

## 3. 挖宝流程

```
选择挖宝点 / 点击「挖一层」
  → 消耗：铲子 ×1 或 金币（如 50~200，随回合涨）
  → 随机事件 roll（权重表）
  → 结算奖励 or 惩罚
  → 可连续挖（赌到停）或收手离开
```

**连续挖**：同一 visit 内每层难度/奖励权重可略升 — 越挖越赌。

---

## 4. 事件类型（赌狗核心）

| 事件 ID | 权重 | 结果 |
|---------|------|------|
| `loot_common` | 高 | 金币、白绿装、普通球 |
| `loot_rare` | 中 | 蓝紫装、强化石、保护石 |
| `loot_jackpot` | 低 | 橙装、大师球、高级保护石 |
| `trap_empty` | 中 | 什么都没有，消耗已付 |
| `trap_collapse` | 低 | 扣金币 10%~30% |
| `trap_mimic` | 低 | 召唤一只精英怪，击败才给宝（战斗弱英雄很难受） |
| `curse_layer` | 极低 | 下一层奖励 ×2 但再失败惩罚 ×2 |

产出池受 **luck、wealth、技能** 修正（见 [25 §3.1](./25-属性系统设计.md)）。  
trap 惩罚受 **maxHp、armor** 减免。

---

## 5. 与养成系统联动

挖宝是 **材料入口**，不只给金币：

| 产出 | 用途 |
|------|------|
| 装备 | 6 格栏、合成升品质 |
| 强化石 / 保护石 | [14-强化室](./14-强化室.md) |
| 附魔石 | [15-附魔台](./15-附魔台.md) |
| 精灵球 / 大师球 | [11-抓宠](./11-抓宠模块.md)（抓宠英雄可卖或自用） |
| 铲子 | 继续挖 |

**挖宝英雄自己不擅长战斗**，但挖出的战斗装可以给任何 build 用，或下局换英雄（若做局外）。

---

## 6. 铲子与探测道具

| 道具 | 作用 |
|------|------|
| 铁铲 | 挖 1 层，标准权重 |
| 金铲 | luck + wealth 联动提高稀有权重；trap 惩罚仍看 maxHp/armor |
| 探测符 | 本 visit 下一次事件预览（高级货） |
| 藏宝图 | 跳过 trap 一层（一次性） |

---

## 7. 平衡要点

- 挖宝英雄 baseStats：攻击约为输出英雄的 **55%~65%**，血量 **60%**
- 被动 **不加** 攻击/生存，只加挖宝相关
- 靠挖出的装备 + 局内属性选择补刀
- 「连续挖 5 层不出货」应有保底或权重补偿（配置 `pity-dig.json`）

---

## 8. UI

- 地层深度计数「第 N 层」
- 事件结果大图标：宝箱 / 陷阱 / 怪从土里钻出
- 收手按钮始终可见 — 鼓励「见好就收」
