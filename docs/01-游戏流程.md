# 01 — 整体游戏流程

[← 返回索引](./README.md)

## 流程图

```
主界面（选地图）
    ↓
战前准备（选英雄 → 选初始道具 → 选初始装备）
    ↓
┌─────────────────────────────────────────────┐
│  局内循环（按回合时间推进）                    │
│                                             │
│  [战斗回合] 自动战斗，计时结束                  │
│       ↓                                     │
│  [属性选择] 4 选 1，可金币刷新（递增价）         │
│       ↓                                     │
│  [回合商店] 购买道具 / 装备 / 强化石 / 附魔石   │
│       ↓                                     │
│  （第 5 回合起）概率进入特殊场所                 │
│       → 赌场 / 拍卖行 / 强化室 / 附魔台         │
│       ↓                                     │
│  下一回合 …                                  │
└─────────────────────────────────────────────┘
    ↓
局结束（胜利 / 失败）→ 结算 → 返回主界面
```
