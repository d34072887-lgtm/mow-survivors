# 05 — 难度与刷怪 Spawn

[← 返回索引](./README.md)

## 设计原则

**慢慢变强、慢慢变难** — 前期不能一刀清屏，难度与养成同步爬坡。

## 第 1 回合（已确认）

| 项 | 值 |
|----|-----|
| 怪物数量 | 约 **15 只**（回合内总量，待确认是否=场上上限） |
| 种类 | 从地图普通怪池 **随机** |
| 精英 / Boss | 无 |
| 单回合时长 | 约 15 秒 |

## 后续回合

- 数量、刷新频率递增
- 普通怪属性按 `difficulty-curve.json` 倍率提升
- 中后期混入精英，特定回合出 Boss

## 配置示例

```json
{
  "round": 1,
  "duration": 15,
  "spawnTotal": 15,
  "pool": ["slime", "bat", "goblin"],
  "eliteChance": 0,
  "bossId": null
}
```

## 双曲线（建议）

| 曲线文件 | 控制 |
|----------|------|
| `playerPowerBudget` | 每回合预期金币、商店品质 |
| `enemyThreatBudget` | 刷怪数、精英率、Boss、属性倍率 |

调平衡只改 `spawn-rules/` 与 `difficulty-curve.json`，不改怪物单文件。
