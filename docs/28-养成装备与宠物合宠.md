## 1. 一句话

内容**不用靠一堆解锁菜单往外扩**：地图往后走，怪数值与机制变强，装备渐渐放出更强的；宝石一路可镶；宠物是**挂在玩家身上的被动战力**（不下场打架），看**资质**与**技能/合宠**，前期带 1 只、后期最多 3 只。幸运关前期也能**小概率**开到后期货，刷图才有新鲜感。

---

## 2. 已确认

### 2.1 进度怎么变丰富（不做「通关解锁难度档」为主）

| 项 | 约定 |
|----|------|
| 主轴 | **按地图推进慢慢放内容**（翠绿草场 → 余烬高地 → …），不是靠打过 BOSS 解锁「精英/噩梦」菜单当主要内容扩展 |
| 装备 | 后期怪更硬、机制更多 → **更强装备慢慢放出**；玩家拿到的装要能跟上 |
| 宝石 | **镶嵌**贯穿全程（孔数/石头强度可随后期变强，细则另开） |
| 宠物数量 | 池子慢慢变多；**前期只能带 1 只，后期最多带 3 只** |
| 同一章 | 可反复刷养成（见 27：第一章可能刷十来次才第一次打过 BOSS） |

### 2.2 幸运关与「超前掉落」

| 项 | 约定 |
|----|------|
| 目的 | 反复刷时仍有惊喜，不是纯肝数值 |
| 可开出 | 后期才常见的装备 / 材料；**无级别限制**类型；**自带特级**的装备 |
| 手感 | **能开到，但要稀**（偶有惊喜，避免前期直接毕业）——具体概率表第一版实现时再填数 |

### 2.3 武器处理

| 项 | 约定 |
|----|------|
| 不要的武器 | 可 **卖**（换钱）或 **分解**（换材料，供强化/镶嵌/合成等） |
| 选择 | 玩家自选，不强制 |

### 2.4 宠物定位（与旧「下场打架宠」区分）

| 项 | 约定 |
|----|------|
| 像梦幻的哪里 | **资质差异、合宠追求、技能深度** |
| 不像梦幻的哪里 | **宠物不下场打架**；按宠的能力 **直接给玩家加属性/战力** |
| 被动 | 每只/每种定位不同（例：金猪 → 提高幸运关概率）；**流派不同，用的宠不同** |
| 强弱看什么 | **每只宠自己的资质卷面**，不是白/绿/蓝/紫/橙那种固定品阶招牌 |
| 隐藏技能 | **每种我们设定的宠物，都要有一个独特机制向的隐藏技能**（金猪类可定位为隐藏被动） |
| 野生 | **只有 1 个技能** |
| 合成后 | **技能数量不设上限**；被动可合成，类似梦幻合宠 |
| 极品难度 | **故意难出极品**——合很多次也不一定全对，留长期追求 |
| 出战栏 | 前期 1 栏 → 后期最多 3 栏（如何随地图/进度放开，实现时再定默认） |

**样板**：「金猪」——隐藏向被动，提高幸运关相关概率；合宠才更容易追求隐藏/多技能极品。

### 2.5 与 [11-抓宠模块](./11-抓宠模块.md) 的关系

- 旧 11 偏「击杀捕获 + 同种数量合并 + 宠可出战」——**局内抓宠职业向**。
- 本文是 **账号养成向**：资质、被动/隐藏技能、合宠、带 1～3 只给玩家加战力。
- **两套可并存**：局内捕获可进养成栏；养成规则以本文 + 后续数值表为准。冲突时以产品最新沟通（本文）为准，并在改 11 时显式修订。

## 3. 第一版（v0.1 可玩）建议范围

> 目标：用户能打开就玩；先立骨架，合宠/镶嵌细则可后补。

| 纳入 | 暂缓 |
|------|------|
| 沿用现有：主界面 → 约 5 回合割草 → 4 选 1 → 结算 | 完整合宠数值、极品公式 |
| 本章加载时标记 **1 个幸运回合**（更高压力 + 失败不罚进度） | 完整宝石孔与镶嵌 UI |
| 结算/掉落：**账号向**装备或材料占位；幸运关 **极低概率** 超前掉落提示 | 全宠物图鉴与全隐藏技能 |
| 背包：武器 **卖 / 分解** 最小按钮 | 第 2、第 3 宠位完整成长线 |
| **1 只样板宠**（如金猪）：资质数字 + 1 个被动说明 + 给玩家加一点可见属性 | 多宠合宠完整流程（可只留「合宠」入口灰态或极简 demo） |

敲定原则：**能连打一章、能感到幸运关与养成掉落、能看见宠物加在自己身上**；其余按文档迭代。
